## 📖 Sobre o projeto

A **Calculadora de IMC** é um site feito com HTML, CSS e JavaScript. O usuário informa o peso e a altura e o programa calcula o Índice de Massa Corporal.

O cálculo é feito com a fórmula:

```
IMC = peso (kg) / altura² (m)
```

## 📊 Classificação

| IMC | Classificação |
|-----|---------------|
| Abaixo de 18,5 | Abaixo do peso |
| 18,5 a 24,9 | Peso normal |
| 25,0 a 29,9 | Sobrepeso |
| 30,0 a 34,9 | Obesidade grau I |
| 35,0 a 39,9 | Obesidade grau II |
| 40,0 ou mais | Obesidade grau III |

> ⚠️ O IMC é apenas uma referência e não substitui a avaliação de um profissional de saúde.
